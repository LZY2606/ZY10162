# 寒层年尺

冰芯 **深度 → 年代** 单调年尺的本地服务。在**没有任何外部数据服务**的前提下，
综合季节层计数、火山灰锦标、同位素对齐点与芯段缺失记录，构建年龄随深度不减的
单调年代曲线，保留局部分层的多个合理方案，并对每次求解留存不可变运行记录。

技术栈：Rust + Axum + SQLite（rusqlite bundled，无需系统 SQLite）+ 原生 Web UI。

## 快速开始

```bash
cargo fetch --locked

# 自动化测试
cargo test --locked

# 启动演示服务
cargo run --locked -- --listen 127.0.0.1:5502
# 浏览器访问 http://127.0.0.1:5502 ，页面标题为「寒层年尺」
```

可选参数：`--db <sqlite 路径>`（默认 `./hanceng.sqlite`）。

## 数据口径（重要）

- **深度**：自上而下递增，单位米。芯段允许在边界处恰好相接，但必须严格有序、
  互不重叠（`bottom > top`，下一段 `top >= 上一段 bottom`）。
- **年龄**：以“距表层年数”计，表层锚点 `A0 = 0`；年龄随深度**不减**
  （允许零增长，但不允许倒序）。
- **缺芯**：`present=false` 的芯段必须给出 **`gap_min_years > 0`**，
  缺芯两侧年龄差至少为该值；**严禁以零年填补**（API 会返回 400）。
- **硬约束锦标**：年龄必须落在 `[lo, hi]`。同一深度两个硬区间
  - 无交集（`lo1 > hi2` 或 `lo2 > hi1`）→ **拒绝发布**，返回**最小冲突集**；
  - 恰好相触（边界相等）→ **可行解**。
- **软约束锦标**：`[lo, hi]` 是截断正态分布的支撑，`mean/sd` 为分布参数；
  `alt_means` 非空时表示**局部分层的多个合理方案**，每次抽样等概率离散选取，
  分位数因此呈现多峰混合。
- **可交换软锦标**：同一 `exchange_group` 内的软锦标可整体对调年龄归属
  （例如两次难以区分的火山灰），交换状态本身也进运行快照。

### 求解方法

1. 把芯段边界与全部锦标深度（含被排除锦标的深度，作为自由插值节点）作为有序节点；
2. 硬盒约束 + 缺芯下界构成差分约束系统，先用前/后包络判可行，
   不可行时用最长路前驱链回溯候选冲突集，再逐一删除验证**极小性**；
3. 可行时做蒙特卡洛抽样：每个锦标在 `(draw, 锦标 id, solver_version)`
   派生的**确定性子流**上抽样，经 Dykstra 交替投影（加权 PAVA + 硬盒 +
   缺芯偏移）与活动集块求精，得到加权最小二乘意义下的单调解；
4. 输出每个深度的 q05 / 中位数 / q95、每个深度段的局部累积率（年/米；
   缺芯段为年数），以及每个分位数依赖的锦标/缺芯键集合。

### 确定性与重放

- 随机源为自带的 xoshiro256\*\* + Box-Muller（`src/rng.rs`），**不调用系统随机**；
- 相同 `(seed, draws, solver_version, 输入快照)` 重放，分位数**逐位一致**；
- 固定演示种子 `20260921`、默认 400 次抽样（见 `src/fixtures.rs`）。

## 固定 fixture（验收场景）

- 芯段：`S1 0–12m`、`S2 12–21.8m`、**`S3 21.8–22.4m 缺芯（最小 30 年）****、`S4 22.4–30m`；
- 两个可交换软锦标：`V15@15m`、`V20@20m`（交换组 `EX-V`，UI 可对调）；
- 一对互相冲突的硬年代区间：`I28@28m [180,190]` 与
  **`C25B@28m [150,165]`**（`C25B` 默认排除，勾选即进入“冲突版本”）；
- `L9@9m` 带三个局部层计数方案 `43/45/47`。

页面上可直接完成验收四步：

1. **求解** → 得到可行模型、中位数/区间/局部累积率；
2. 勾选 `C25B` 的“排除”列取消排除 → 再次求解 → 红色横幅给出最小冲突集
   `{I28, C25B}`，该次运行以 `rejected` 留档；
3. 编辑缺芯 `S3` 最小年数（如 30→45）→ 选基线点“增量重放” →
   只有依赖该缺芯的分位数失效，缺芯之上远处节点逐位复用；
4. 交换组选“对调归属” → 重放 → 用“候选模型差异定位”选两条运行对比，
   差异按深度段列出。

## 增量失效口径

“增量重放”对比两次输入快照：

- 仅某锦标变化（分布参数/排除/恢复）→ 只失效依赖集合含该锦标的节点/边；
- 仅某缺芯的 `gap_min_years` 变化 → 只失效依赖集合含该缺芯的节点/边；
- 深度结构、种子、抽样数变化 → 全量失效；
- 对每一个“声称复用”的分位数，都用重算结果做**逐位相等硬校验**，
  因全局最小二乘耦合出现微弱数值漂移时保守判失效（正确性优先于复用率）。

## 不可变运行记录 / 导出 / 导入复核

- 每次求解（含被拒绝）都在 `runs` 表追加一条记录：序号、类型、状态、
  种子、抽样数、**完整输入快照**、结果 JSON、冲突集 JSON、父运行序号、
  增量重放报告；记录只追加、不修改。
- `导出 Bundle`（页面按钮或 `GET /api/export`）下载含状态与全部记录的 JSON；
- `清空数据库` 后 `导入并复核`（`POST /api/import`）：对每条记录**按其快照
  重新求解**，feasible 记录逐位核对 q05/中位数/q95 与速率，rejected 记录
  核对最小冲突集；**任一不可复现则拒绝导入且不改动数据库**。

## HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 芯段/锦标/交换组/运行摘要 |
| POST | `/api/solve` | 用当前状态求解，追加运行记录 |
| POST | `/api/rerun` | 以某运行为基线增量重放 |
| GET | `/api/runs` / `/api/runs/{seq}` | 运行列表 / 明细 |
| GET | `/api/runs/{a}/diff/{b}` | 两个候选模型按深度段的差异 |
| POST | `/api/markers/{id}` | 调整锦标分布/排除/区间等 |
| POST | `/api/segments/{id}` | 调整芯段/缺芯边界 |
| POST | `/api/exchanges` | 设置交换组对调状态 |
| GET/POST | `/api/export` / `/api/import` | 导出 Bundle / 清空后导入复核 |
| POST | `/api/admin/reset` / `/api/admin/clear` | 重置 fixture / 清空数据库 |

## 目录结构

```
src/
  main.rs          入口（建库、写初始基线、启动 Axum）
  model.rs         领域类型与严格有序/缺芯校验
  rng.rs           固定种子确定性随机源
  solver.rs        可行性/最小冲突集/PAVA+Dykstra/MC 分位数/依赖追踪
  incremental.rs   快照 diff 与增量复用（逐位硬校验）
  fixtures.rs      固定验收数据
  db.rs            SQLite 状态表与不可变 runs 表
  exchange.rs      Bundle 导出与导入重放复核
  api.rs           Axum JSON API
static/            原生操作页面（index.html / app.js / styles.css）
tests/             自动化测试（HTTP 全流程、增量失效、导出导入复核）
```
